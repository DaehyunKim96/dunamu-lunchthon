# 직관 스토리 덱 (`/story`) — 컨셉 정의서

> 두아이 런치톤(사내 AI 해커톤) 회고 발표용 덱의 단일 기준 문서.
> 기존 공식 제품 덱(`/presentation`, `Presentation.jsx`)과는 **의도적으로 다른 톤**을 가진다.
> 덱을 수정할 때는 이 문서와의 일관성을 유지하거나 이 문서를 함께 갱신한다.

---

## 1. 목적과 청중

| 항목 | 내용 |
|---|---|
| 목적 | 제품 피칭이 아니라 **"왜 이렇게 만들게 되었는가"의 회고** |
| 청중 | 사내 동료 (해커톤 참가자·비참가자 혼재, 블록체인 비전공자 다수) |
| 분량 | Q&A 포함 20~30분 · 슬라이드 31장 |
| 언어 | 한국어, **전 문장 개조식** (명사형 종결, 서술형 문장 금지) |
| 경로 | `/story` (기존 `/presentation`은 그대로 유지) |

---

## 2. 스토리 구조 — 6막 여정 (Journey / Hero's Path)

시간 순 인과 사슬로 전개한다. 각 막은 **하나의 질문**에 답한다.

| 막 | 질문 | 슬라이드 |
|---|---|---|
| 00 | 오프닝 | 1~2 |
| 01 | 어떻게 시작했나 | 3~7 |
| 02 | 왜 블록체인이었나 | 8~11 |
| 03 | 왜 암표였나 | 12~15 |
| 04 | 왜 GIWA였나 | 16~21 |
| 05 | 무엇이 나왔나 | 22~27 |
| 06 | 무엇이 남았나 | 28~31 |

핵심 전환점은 **슬라이드 21**이다. "인증된 지갑 = 나 자신" → "인증된 지갑 간 거래 = 암표 차단"의
논리 연결이 이 발표 전체의 결론이며, 여기서 제품이 등장한다.

## 3. 디자인 컨셉 — "손그림 노트 (Hand-drawn Notebook)"

레퍼런스: Fork(Git 클라이언트) 소개 영상의 화이트보드 드로잉 톤.
**AI 스러움(네온 그라디언트 · 다크 글래스모피즘 · 보라/청록)을 전면 배제**한다.

### 3.1 컬러 토큰 (총 5색)

| 토큰 | 값 | 역할 | 비중 |
|---|---|---|---|
| `--paper` | `#FBF7ED` | 종이 배경 | 60% |
| `--ink` | `#2E2A26` | 손글씨 잉크 (본문·테두리) | 30% |
| `--sky` | `#4A9FD4` | 주 강조 (Fork 블루) | 6% |
| `--marker` | `#E0574C` | 경고·문제 지점 | 3% |
| `--hl` | `#FFDE7A` | 형광펜 하이라이트 | 1% |

보조: `--ink-soft #6E655A` (본문 저채도), `--go #6FAE74` (검증/통과 표시).

### 3.2 타이포그래피

| 용도 | 폰트 | 비고 |
|---|---|---|
| 한글 전체 | **Gaegu** 300/400/700 | 크레용·연필 느낌. 시각적으로 작게 보여 기준 크기를 10~15% 키움 |
| 라틴·숫자 강조 | **Caveat** 400/600/700 | 섹션 번호, 영문 캡션, 낙서 라벨 |

폰트는 `/story` 진입 시에만 `<link>` 주입으로 로드한다 (메인 앱 성능 미영향).

### 3.3 형태 규칙

- **손그림 테두리**: `border-radius: 255px 15px 225px 15px / 15px 225px 15px 255px` + `2.5px solid ink`
- **손배치 느낌**: 카드마다 `-0.8deg ~ 0.7deg` 미세 회전 (짝수/홀수 교차)
- **형광펜**: `linear-gradient(180deg, transparent 58%, var(--hl) 58% 92%, transparent 92%)`
- **종이 질감**: `feTurbulence` SVG noise 데이터 URI, opacity 0.045
- **낙서 요소**: 화살표·별·동그라미·체크는 전부 인라인 SVG 패스 (아이콘 폰트/이모지 미사용)

### 3.4 하지 말 것

- 그라디언트 배경, 네온 글로우, 글래스모피즘, 드롭섀도 남발
- 다크 모드 (이 덱은 라이트 전용)
- 이모지로 아이콘 대체
- 서술형 문장 ("~입니다", "~했습니다") — **전부 개조식**

## 4. 레이아웃 시스템

슬라이드는 아래 레이아웃 컴포넌트만 사용한다. 개별 슬라이드에서 임의 스타일링 금지.

| 레이아웃 | 용도 |
|---|---|
| `Cover` | 표지 |
| `Agenda` | 6막 목차 |
| `Section` | 막 구분 (큰 손글씨 번호 + 질문) |
| `Bullets` | 제목 + 리드 + 개조식 목록 (기본형) |
| `TwoUp` | 두 선택지·두 판단 비교 |
| `Steps` | 좌→우 흐름 + 스케치 화살표 |
| `Logic` | 세로 논리 사슬 (전환점 슬라이드) |
| `Hero` | 이미지 전면 + 스케치 프레임 |
| `Blockers` | 문제 ↔ 차단 대응 4행 |
| `Closing` | 마무리 + 링크 |
